## 六、性价比分析

> 16GB 环境下的性价比 = 质量得分 / (显存需求 × 生成时间)，归一化处理。

### 6.1 性价比计算

```
显存效率 = 综合Elo / 峰值显存(GB)
速度效率 = 综合Elo / 平均耗时(s)
综合性价比 = (显存效率 × 0.6 + 速度效率 × 0.4) × 归一化系数
```

### 6.2 性价比排名
