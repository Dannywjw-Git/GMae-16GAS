## 协作与事实来源

本 Work 会话负责主要技术执行；另一个 Chat 会话负责战略、架构复核、参赛竞争力评估和独立质量监督。GitHub 仓库是双方唯一共享事实来源。未提交文件、隐藏记忆和非公开推理不能作为交接证据。没有保证实时生效的直接通信机制；提交更新不代表 Chat Agent 已收到通知或开始评审。

每个重要阶段使用独立分支和 Draft PR。阶段完成后推送代码、测试证据以及本文件、[决策记录](DECISIONS.md)、[交接记录](HANDOFF.md)。执行 Agent 持续推进最高优先级任务，无须等待独立评审；发现重大设计缺陷或验收阻断时优先修复。用户可随时要求 Chat Agent 读取最新 PR。
