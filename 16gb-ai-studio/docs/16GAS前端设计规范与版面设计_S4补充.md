**尺寸规范**：
- Header：高度 52px，背景 `--color-bg-1`，底部边框 1px `--color-border`
- Sidebar：宽度 220px（可折叠到 56px 仅图标），背景 `--color-bg-1`，右边框 1px
- Content：padding 24px，最大内容宽度 1400px（居中），背景 `--color-bg-0`
- 页面标题区：高度 40px，标题 20px semibold + 副标题 12px secondary

### 1.3 组件库规范

#### Button 按钮

| 变体 | 背景 | 文字 | 边框 | 用途 |
|------|------|------|------|------|
| primary | `--color-brand-600` | `--color-text-inverse` | 无 | 主操作（确认、提交、执行） |
| secondary | `--color-bg-3` | `--color-text-primary` | `--color-border` | 次操作（取消、返回） |
| danger | `--color-danger` | white | 无 | 危险操作（删除、驱逐、停止） |
| ghost | transparent | `--color-text-secondary` | 无 | 图标按钮、文字链接 |
| success | `--color-success` | white | 无 | 确认释放、执行成功 |

**尺寸**：
- sm：高 28px，padding 0 10px，字号 12px，圆角 5px
- md：高 34px，padding 0 14px，字号 13px，圆角 5px（默认）
- lg：高 40px，padding 0 18px，字号 14px，圆角 8px

**状态**：default / hover（亮度+10%）/ active（亮度-10%）/ disabled（opacity 0.5，cursor not-allowed）/ loading（spinner + 文字变暗）

#### Card 卡片

```
┌──────────────────────────────────┐
│  卡片标题（14px semibold）    [操作] │  ← header（padding 12px 16px，底部边框）
├──────────────────────────────────┤
│                                  │
│  卡片内容（padding 16px）         │
│                                  │
└──────────────────────────────────┘
```

- 背景 `--color-bg-2`，边框 1px `--color-border`，圆角 8px
- 可选 header（标题 + 右侧操作区）
- 可选 footer（操作按钮区）
- hover 时边框变为 `--color-border-focus`（可选，用于可点击卡片）

#### Badge 标签

| 类型 | 背景 | 文字 | 用途 |
|------|------|------|------|
| success | `rgba(34,197,94,0.15)` | `--color-success` | 在线、正常、已完成 |
| warning | `rgba(245,158,11,0.15)` | `--color-warning` | 启动中、等待、警告 |
| danger | `rgba(239,68,68,0.15)` | `--color-danger` | 危险、异常、失败 |
| critical | `rgba(220,38,38,0.2)` | `--color-critical` | 致命、OOM |
| info | `rgba(59,130,246,0.15)` | `--color-info` | 进行中、信息 |
| neutral | `--color-bg-3` | `--color-text-secondary` | 默认、未知 |

- 高度 20px，padding 0 8px，圆角 3px，字号 11px，medium 字重
- 可选圆点前缀（8px 圆点 + 4px 间距）

#### Progress 进度条

- 高度：4px（细）/ 8px（标准）/ 12px（粗）
- 背景：`--color-bg-3`，圆角 full
- 填充：品牌色或语义色，圆角 full
- 可选文字标签（百分比在右侧）

#### Table 表格

```
┌──────────────────────────────────────────────────────┐
│  列头1      列头2      列头3      列头4           [操作] │  ← thead（背景 bg-3，字号 12px，文字 secondary）
├──────────────────────────────────────────────────────┤
│  内容       内容       内容       [badge]         [按钮] │  ← tbody 行（hover 背景 bg-hover）
│  内容       内容       内容       [badge]         [按钮] │
│  ...                                                    │
└──────────────────────────────────────────────────────┘
```

- 行高 40px，padding 0 16px
- 列间距用 padding，不用 border-collapse
- 行之间用底部 1px 边框 `--color-border-light` 分隔
- hover 行背景 `--color-bg-hover`
- 选中行背景 `--color-bg-active`，左边框 2px 品牌色

#### Modal 弹窗

- 遮罩：`rgba(0,0,0,0.6)`，backdrop-filter blur(4px)
- 弹窗：背景 `--color-bg-2`，边框 `--color-border`，圆角 16px，阴影 `--shadow-xl`
- 尺寸：sm（400px）/ md（560px，默认）/ lg（720px）/ xl（900px）
- 结构：header（标题 + 关闭按钮）/ body（内容，padding 24px）/ footer（操作按钮，右对齐）
- 动画：scale 0.95→1 + opacity 0→1，200ms

#### Drawer 抽屉

- 从右侧滑入，宽度 480px（默认）/ 640px（宽）
- 遮罩同 Modal
- 结构：header（标题 + 关闭）/ body（滚动内容）/ footer（可选操作）
- 动画：translateX(100%)→0，300ms ease-out

#### Toast 通知

- 位置：右上角，堆叠排列，间距 8px
- 尺寸：宽 360px，最小高度 56px
- 结构：左侧图标（语义色）/ 中间（标题 + 描述）/ 右侧（关闭按钮 + 操作按钮）
- 变体：success / warning / danger / info
- 自动消失：4 秒（info/success）/ 8 秒（warning/danger），hover 暂停
- 动画：translateX(100%)→0，250ms

#### Tooltip 提示

- 触发：hover 元素 300ms 后显示
- 位置：top（默认）/ bottom / left / right，自动避让边界
- 样式：背景 `--color-bg-3`，文字 12px primary，padding 6px 10px，圆角 5px，阴影 md
- 箭头：8px 三角形

## 二、全局页面结构

### 2.1 应用框架

#### Header（顶部栏，高 52px）

```
┌──────────────────────────────────────────────────────────────────────┐
│ [GMae]  16G-AI-Studio      [🔔 2]  [GPU 10.6G ▁▂▃▅]  [Danny] [退出] │
│  品牌    页面标题（动态）     告警徽章  显存微缩条        用户   退出   │
└──────────────────────────────────────────────────────────────────────┘
```

**元素说明**：
- 品牌区（左）：GMae logo（SVG，24px）+ "16G-AI-Studio" 文字（14px semibold），点击回 Dashboard
- 页面标题（左，品牌区右侧）：当前页面名称（13px secondary），如"诊断中心"
- 告警徽章（右）：铃铛图标 + 未读告警数（badge，danger 色），点击跳告警中心；无告警时仅图标
- 显存微缩条（右）：迷你显存水位条（宽 80px，高 8px）+ 空闲数值（12px mono），hover 显示详情 tooltip；点击跳显存账本
- 用户区（右）：用户头像（圆形，28px，首字母）+ 用户名（12px），hover 显示下拉菜单（个人设置/改密/退出）
- 退出按钮（最右）：ghost 按钮，图标 + "退出"

#### Sidebar（侧边栏，宽 220px）

```
┌──────────────┐
│              │
│  📊 总览     │  ← 选中项：背景 bg-active，左边框 2px 品牌色，文字 primary
│  🩺 诊断中心 │     未选中：文字 secondary，hover 背景 bg-hover
│  🔔 告警中心 │     有 badge 时右侧显示数字
│  ─────────  │  ← 分隔线（border-light）
│  📦 模型     │
│  💾 显存账本 │
│  🎬 场景     │
│  📋 队列     │
│  🛡️ 门卫     │
│  ─────────  │
│  ⚙️ 设置     │
│              │
│              │
│  v1.0.0      │  ← 底部版本号（11px tertiary，居中）
└──────────────┘
```

## 五、CSS 架构与命名规范

### 5.1 BEM 命名规范

```css
/* Block: 组件名 */
.card { }

/* Element: 组件内元素，用 __ 分隔 */
.card__header { }
.card__body { }
.card__footer { }

/* Modifier: 状态/变体，用 -- 分隔 */
.card--clickable { }
.card--danger { }
.card__title--large { }

/* 状态类：用 is- 前缀 */
.is-active { }
.is-loading { }
.is-hidden { }
```

### 5.2 文件组织

- `variables.css`：纯变量定义，无样式
- `reset.css`：浏览器样式重置
- `main.css`：@import 所有组件 CSS + 全局布局/工具类
- 组件 CSS：一个组件一个文件，只包含该组件的样式
- 页面 CSS：内联在组件中或单独文件（本设计中页面样式复用组件，不单独建页面 CSS）

### 5.3 性能优化

- CSS 变量：运行时可切换主题（暗色/亮色），无需重新编译
- 避免嵌套过深：最多 3 层（BEM 天然扁平）
- 避免 `!important`：用特异性解决
- 动画：只用 `transform` 和 `opacity`（GPU 加速），避免 `width/height/top/left` 动画
- 图片：SVG 优先，PNG 用 WebP 替代
