在 `core/logger.py` 中添加辅助函数（如已存在则跳过）：

```python
def log_exception(logger, context: str, exc: Exception, level: str = "warning"):
    """统一异常记录格式
    Args:
        logger: 日志记录器
        context: 上下文描述（如"加载模型qwen3.5:9b"）
        exc: 异常对象
        level: 日志级别（warning/error）
    """
    getattr(logger, level)(f"{context}失败: {type(exc).__name__}: {exc}", exc_info=True)
```

**A. `clients/process_client.py` — 子进程调用统一封装**

```python
"""子进程调用统一客户端
封装 subprocess 调用，提供统一的超时、错误处理、日志记录
"""
import subprocess
import logging
from dataclasses import dataclass
from typing import Optional, List, Dict

logger = logging.getLogger(__name__)

@dataclass
class ProcessResult:
    """子进程执行结果"""
    returncode: int
    stdout: str
    stderr: str
    success: bool

class ProcessClient:
    """子进程调用客户端"""
    
    def __init__(self, default_timeout: int = 30):
        self.default_timeout = default_timeout
    
    def run(self, cmd: List[str], timeout: Optional[int] = None, 
            cwd: Optional[str] = None, env: Optional[Dict] = None) -> ProcessResult:
        """执行子进程命令
        Args:
            cmd: 命令列表（如 ['docker', 'ps', '-a']）
            timeout: 超时时间（秒），默认使用 default_timeout
            cwd: 工作目录
            env: 环境变量
        Returns:
            ProcessResult 执行结果
        """
        timeout = timeout or self.default_timeout
        try:
            result = subprocess.run(
                cmd,
                capture_output=True,
                text=True,
                timeout=timeout,
                cwd=cwd,
                env=env
            )
            return ProcessResult(
                returncode=result.returncode,
                stdout=result.stdout,
                stderr=result.stderr,
                success=result.returncode == 0
            )
        except subprocess.TimeoutExpired as e:
            logger.error(f"命令超时({timeout}s): {' '.join(cmd)}")
            return ProcessResult(returncode=-1, stdout="", stderr=f"Timeout: {e}", success=False)
        except Exception as e:
            logger.error(f"命令执行失败: {' '.join(cmd)}: {e}", exc_info=True)
            return ProcessResult(returncode=-1, stdout="", stderr=str(e), success=False)
```

**具体方案**：

#### 步骤1：审计所有模块级可变变量

全局搜索以下模式：
- 模块级字典/列表赋值（`_xxx = {}`、`_xxx = []`）
- 模块级对象实例（`_xxx = SomeClass()`）
- 全局变量修改（`global xxx`）

#### 步骤2：分类处理

| 变量类型 | 处理方式 |
|---------|---------|
| 配置常量 | 保留（不可变，无需移入 Registry） |
| 缓存数据 | 移入 Registry 或用专用缓存类 |
| 服务状态 | 必须移入 Registry |
| 任务队列 | 必须移入 Registry |
| 单例实例 | 移入 Registry 或用依赖注入 |

#### 步骤3：Registry 并发保护检查

- [ ] Registry 内部所有读写共享状态的方法都加锁
- [ ] 锁的粒度按状态域划分（不用一把大锁）
- [ ] 死锁风险检查（锁的获取顺序一致）
- [ ] 状态变更记录日志（时间戳、变更前、变更后、触发原因）

#### 验收标准

- [ ] 无模块级可变共享状态（配置常量除外）
- [ ] Registry 所有读写方法有锁保护
- [ ] 状态变更有日志记录
- [ ] 并发测试通过（多线程同时读写无竞态）
