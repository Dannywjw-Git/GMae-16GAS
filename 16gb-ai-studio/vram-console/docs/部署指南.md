## 快速部署（推荐）

### Windows

```bash
# 1. 克隆仓库
git clone https://github.com/Dannywjw-Git/GMae-16GAS.git
cd GMae-16GAS/16gb-ai-studio/vram-console

# 2. 一键部署（环境检查 + 配置初始化 + 启动服务）
install.bat

# 3. 访问
# 浏览器打开 http://127.0.0.1:8787
```

```bash

# 3. 访问
# 浏览器打开 http://127.0.0.1:8787
```

## 手动部署

### 1. 环境准备

```bash
# 验证 Python
python --version  # 需 3.8+

# 验证 Docker
docker --version

# 验证 NVIDIA GPU
nvidia-smi
```

### 2. 配置初始化

```bash
# 生成 API Token（首次运行自动生成，也可手动创建）
python -c "import secrets; print(secrets.token_hex(32))" > .api_token

# Windows:
echo %RANDOM%%RANDOM%%RANDOM% > .api_token
```

### 3. 启动服务

```bash
# Windows
start.bat

# Linux
chmod +x start.sh
./start.sh
```

### 4. 验证

```bash
# 健康检查
curl http://127.0.0.1:8787/api/health

# 查看状态
# Windows: status.bat
# Linux: ./status.sh
```

## AI 容器管理

GMae 通过 Docker 管理以下 AI 服务容器：

| 容器 | 用途 | 端口 | 显存需求 |
|------|------|------|---------|
| comfyui | 文生图/文生视频 | 8188 | 6-14GB |
| ollama | 本地 LLM 对话 | 11434 | 5-12GB |
| fooocus | 高质量图像生成 | 7860 | 12-16GB |

### 容器启动示例

```bash
# ComfyUI
docker run -d --name comfyui --gpus all -p 8188:8188 \
  -v comfyui_data:/workspace -v comfyui_models:/models \
  yanwk/comfyui-boot:latest

# Ollama
docker run -d --name ollama --gpus all -p 11434:11434 \
  -v ollama_data:/root/.ollama \
  ollama/ollama:latest

# 拉取模型
docker exec ollama ollama pull qwen3.5:9b
```

> **注意**：GMae 不强制要求所有容器都运行，它会根据场景自动启停容器。

## 配置说明

### 核心配置文件

| 文件 | 说明 |
|------|------|
| `.api_token` | API 访问令牌（自动生成） |
| `resources/registry.json` | 服务/模型/场景注册表（自动创建） |
| `resources/scene_state.json` | 当前场景状态（自动创建） |
| `resources/generation_stats.json` | 生成统计数据（自动创建） |

### 场景配置

场景定义在 `registry.json` 的 `scenes` 字段中，支持 6 个预设场景：

- `dialogue` — 对话模式（保留 Ollama，停止图像容器）
- `comfy` — ComfyUI 模式（启动 ComfyUI，停止 Ollama/Fooocus）
- `h3` — H3 视频模式（全卡独占）
- `fooocus` — Fooocus 高质量图像模式（全卡独占）
- `music` — 音乐生成模式（全卡独占）
- `game` — 游戏模式（停止所有 AI 容器，释放显存）

添加新场景只需修改 `registry.json`，无需改代码。

## 常见问题

### Q: 启动后访问 8787 端口无响应？

A: 检查 watchdog 窗口是否有报错，确认 Python 路径正确（WindowsApps stub 不可用）。

### Q: API 返回 401 Unauthorized？

A: 请求头需携带 `X-API-Key: <token>`，token 在 `.api_token` 文件中。

### Q: 场景切换后显存未释放？

A: WSL2 下 `docker pause` 不释放 GPU 显存，GMae 使用 ComfyUI `/free` 端点释放。检查容器日志。

### Q: 16GB 卡能跑哪些模型？

A: 见 `docs/模型评测台帐.md`。核心结论：大模型需串行运行，GMae 负责调度不翻车。

### Q: 如何更新 GMae？

```bash
git pull
# 重启服务
stop.bat && start.bat  # Windows
./stop.sh && ./start.sh  # Linux
```
