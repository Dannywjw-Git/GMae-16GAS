## 限制与下一瓶颈

单次校准、工程余量和整卡采样不能提供统计保证。当前把整卡包络作为预算，同时仍计入背景/噪声，可能重复计量并造成多余卸载。驻留身份推断还存在文件名与登记模型 ID 不一致；seed 46 因此包含不必要释放和冷加载。第一次模型 SHA-256 核验也有明显耗时。进程内缓存绑定容器 ID、文件路径及 dev/ino/size/mtime/ctime，普通不可变模型部署可以复用；不提供恶意保留元数据后的内容篡改防御。进程重启重新校验。

目前只支持原生 SDXL 六类节点及一个指定 checkpoint，不支持未经测量的 LoRA、自定义节点、多模型外推。其他模板仍是未验证估计。真实 GPU 崩溃/取消、多参数网格、混合 AI 负载对照与稳定 Release 均未完成。

下一阶段优先用可信驻留与阶段预算减少重复卸载，控制身份核验及加载条件，再比较无编排/有编排的成功率、端到端耗时、峰值和卸载次数。当前 143.5 秒不能宣称加速。
