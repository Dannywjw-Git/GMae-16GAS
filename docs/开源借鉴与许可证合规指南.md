# GMae 开源借鉴与许可证合规指南

> 创建：2026-09-03
> 用途：GMae 参加开源大赛、后续开源发布时，规范第三方开源项目的借鉴、依赖与归属声明，避免许可证冲突。
> 适用：所有参与 GMae 开发的 Agent（豆包/WorkBuddy/DSH）与开发者。

---

## 一、三种借鉴方式与合规义务

| 方式 | 说明 | 合规义务 |
|------|------|---------|
| A. 学思路自己写 | 参考架构/算法/设计，代码独立实现 | 零义务（思想、算法、架构不受版权保护），建议在开发日志记录参考来源 |
| B. 装成依赖 | pip/npm 安装，通过 API 调用 | 绝大多数许可证允许（GPL 作为独立进程/依赖不构成衍生作品），在依赖清单声明即可 |
| C. 直接复制源码 | 拷贝代码片段或文件到 GMae 仓库 | MIT/Apache/BSD 必须保留原始版权头；GPL/AGPL 会传染整个项目，禁止复制 |

**核心原则：GMae 是调度编排层，不直接 import 模型推理库，天然隔离大部分许可证风险。**

## 三、GMae 必须落地的合规动作

### 1. 项目许可证
- **GMae 主许可证已确定为 MIT**（2026-09-03 确认；子项目 `16gb-ai-studio/LICENSE` 已存在，署名 "16GB AI Studio contributors"）。
- 工作区根目录与子项目均放 `LICENSE` 文件（MIT 全文），保持一致。
- MIT 与 MIT/Apache-2.0/BSD 代码兼容（引入 Apache 代码时保留其版权头与 NOTICE 即可）；**仍不得包含 GPL/AGPL 代码**。

### 2. 第三方声明文件
- 维护 `THIRD_PARTY.md`（或 NOTICE 文件），逐项登记：
  - 项目名 / 版本 / 许可证 / 仓库地址 / 用途 / 使用方式（学思路·依赖·复制代码）
- 每次新增依赖或参考项目时同步更新。

### 3. 复制代码的版权头规范
从 MIT/Apache 项目复制代码时，文件顶部保留：
```python
# Original work Copyright (c) [年份] [原作者]
# Licensed under the MIT License (see THIRD_PARTY.md)
# Modifications Copyright (c) 2026 GMae contributors
```
Apache-2.0 额外要求：记录你修改了该文件（在变更说明/开发日志注明）。

### 4. GPL 红线
- 任何 GPL/AGPL 代码不得复制进 GMae 源码树。
- GPL 程序只能作为**独立外部进程/容器**被 GMae 调度（进程间调用不构成衍生作品）。
- 拿不准某个库是否 GPL 时，优先"学思路重写"或"独立进程调用"，不直接 import。

### 5. 依赖清单
- Python 依赖写入 `requirements.txt`（锁定版本），前端依赖写入 `package.json`。
- 定期用 `pip-licenses` / `license-checker` 扫描依赖许可证，防止传递依赖带入 GPL。

### 6. 开发日志留痕
- 在 `开发日志.md` 中记录："X 模块参考了 Y 项目的 Z 设计（许可证：MIT），独立实现"。
- 既是合规证据，也是参赛时证明工作量与原创性的材料。

## 四、开源大赛检查清单

- [ ] 仓库根目录与子项目均有 `LICENSE`（MIT）
- [ ] 有 `THIRD_PARTY.md`，第三方组件/参考项目全部登记
- [ ] 复制的 MIT/Apache 代码保留了版权头
- [ ] 源码树中无 GPL/AGPL 代码（MMGP 等只做外部进程/纯思路参考）
- [ ] requirements.txt / package.json 依赖与实际使用一致
- [ ] 开发日志记录了关键设计的参考来源
- [ ] 无未授权的商标/图标/文案直接使用
- [ ] 敏感信息（密码、token、个人配置）已从提交中排除

## 五、快速判断流程

```
想借鉴一个开源项目
  ├─ 只是学它的思路/架构，自己写代码？ → 直接做，日志留痕即可
  ├─ 想装成依赖调用？
  │    ├─ MIT/Apache/BSD → 装，登记依赖清单
  │    ├─ LGPL → 可动态链接/调用，不修改它
  │    └─ GPL/AGPL → 只能独立进程调用，不能 import 进 GMae 源码
  └─ 想复制它的源码？
       ├─ MIT/Apache/BSD → 保留版权头，登记 THIRD_PARTY.md
       └─ GPL/AGPL → 停止，改为学思路重写或独立进程
```
