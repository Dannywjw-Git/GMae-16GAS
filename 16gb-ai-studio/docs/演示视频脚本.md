### 段落 3：核心功能演示（0:50 - 2:50）

#### 3.1 显存账本（0:50 - 1:10）

**画面**：
- 切换到"账本"页面
- 展示显存分布饼图：底噪/对话模型/生成引擎/空闲
- 展开进程级显存明细，展示每个容器/进程的显存占用
- 鼠标指向 Helper 状态卡片

**解说词**：
> "首先是显存账本。每一块显存去哪了，一目了然——Docker 容器、底噪、桌面进程，精确到 MB。这是智能调度的基础：看得见，才能管得好。"

#### 3.2 场景切换（1:10 - 1:40）

**画面**：
- 切换到"场景"页面
- 当前是对话态（qwen3.5:9b 占 10GB）
- 点击"ComfyUI 态"，展示执行日志：停止 Ollama 模型 → 启动 ComfyUI → 显存释放

**解说词**：
> "六大场景一键切换。现在是对话态，9B 模型占了 10GB。点击切到 ComfyUI 态——GMae 自动停止对话模型、释放显存、启动生成引擎，全程不需要手动敲命令。12 秒完成切换。再切回对话态，同样自动。"

#### 3.3 一键释放 + 模型管理（1:40 - 2:05）

**画面**：
- 回到总览页，点击"一键释放"
- 弹出结果弹窗：腾出 10.7GB，已停止的进程列表
- 切换到"模型"页面，展示模型登记台
- 点击"扫描新模型"，展示扫描过程和结果

**解说词**：
> "一键释放，同时停止 Ollama 模型和 ComfyUI 显存，实测腾出 10.7GB。模型管理页支持扫描新模型、自动登记显存预算，加模型只改配置不改代码。"

#### 3.4 自动防死机（2:05 - 2:30）

**画面**：
- 展示 QoS 配置：四级水位（safe/warning/danger/critical）
- 播放实测录像：峰值 15.9GB，空闲 192MB，顶部状态栏变红闪烁
- 弹出危急弹窗，自动触发 L2 驱逐
- 系统未死机，显存回落到安全区

**解说词**：
> "最关键的是自动防死机。四级水位监控，空闲显存低于 2GB 自动驱逐低优先级进程。这是实测画面——峰值 15.9GB，空闲只剩 192MB，GMae 触发紧急释放，系统活下来了。没有 GMae，这时候已经黑屏重启了。"

#### 3.5 任务队列（2:30 - 2:50）

**画面**：
- 切换到"队列"页面
- 展示任务状态机：queued → precheck → freeing → running → done

**解说词**：
> "任务队列支持串行执行，避免多个生成任务同时跑导致显存打满。入队时自动做显存预算预检，不足就排队。半夜批量出图，再也不会全部 OOM。"

## 三、录制要点

### 3.1 录制前准备

- [ ] GMae 服务正常运行（端口 8787）
- [ ] Docker 容器：ComfyUI、Ollama、OWUI 正常
- [ ] 已加载 qwen3.5:9b（对话态演示用）
- [ ] ComfyUI 工作流就绪（SDXL + Flux + Wan2.2）
- [ ] 屏幕分辨率：1920×1080，浏览器全屏
- [ ] 关闭通知、弹窗，避免干扰
- [ ] 准备 OBS 或 Win+G 录制工具

### 3.2 录制技巧

1. **操作放慢**：每个操作停留 2-3 秒，让评委看清楚
2. **鼠标高亮**：用黄色圆圈高亮鼠标位置（OBS 插件）
3. **关键数据放大**：显存数值、释放结果等关键数据可后期放大
4. **错误规避**：如果操作中出现 bug，暂停录制，修复后重录该段
5. **分段录制**：按 5 个段落分段录制，后期拼接，避免一次录到底出错

### 3.3 后期制作

- 配音：用清晰的普通话，语速适中（每分钟 180-200 字）
- 字幕：关键操作加字幕说明，如"一键释放 10.7GB"
- 转场：段落之间用淡入淡出，避免硬切
- BGM：轻快的科技感背景音乐，音量低于人声
- 输出：1080p MP4，H.264 编码，文件大小控制在 200MB 以内
