# 16GB 显卡跑通全模态 AI 生成：我的本地部署踩坑实录

> 从"显存打满死机"到"图/视频/音乐一条龙"，一个消费级显卡的本地 AI 生成环境搭建全记录。

## 为什么要本地部署？

云端 AI 生成有三个痛点：
1. **排队**——高峰期出个视频等半小时
2. **花钱**——视频生成按秒计费，长期用不便宜
3. **隐私**——家庭照片、个人创意不想上传

但本地部署有个硬门槛：**显存**。专业显卡几万块，消费级卡只有 8-16GB。

我用一张 **RTX 4060 Ti 16GB**（约 3000 元），跑通了：
- 🎨 文生图（SDXL + Flux）
- 🎬 文生视频 + 图生视频（MiniMax H3，带原生音频）
- 🎵 AI 写歌（MiniMax Music 3）
- 💬 本地对话（qwen3.5:9b）

这篇文章记录完整的搭建过程和踩过的坑。

## 三、最痛的坑：显存管理

### 教训：显存打满 = 死机

我踩过两次：
1. 第一次：9B 模型开 32K 上下文 → KV cache 爆 → 模型加载失败 → 重试循环 → 内存泄漏 → 死机
2. 第二次：Flux 出图时忘了关 9B 模型 → 16GB 顶格 → 死机

**根因链**：显存打满 → 加载失败 → 重试循环 → 内存泄漏 → 物理内存打满 → 换页 → 死机

### 解决方案：状态机

16GB 装不下所有模型，必须错峰：

```
对话态 ↔ SDXL出图态 ↔ Flux出图态 ↔ 音乐态 ↔ H3出视频态 ↔ 游戏态
```

任意时刻只处于一个状态，切换前必须释放显存到 <4GB。

我写了个 [显存调度中心](https://github.com/Dannywjw-Git/Local-AI-Studio)，Web UI 一键切换场景。

### 显存账本

| 负载 | 显存 | 允许状态 |
|---|---|---|
| 9B 对话 | 6.6-8.4GB | 对话态 |
| SDXL 出图 | ~6.5GB | 出图态 |
| Flux Q5 | ~13GB | 独占全卡 |
| Music3 | ~14.5GB | 独占全卡 |
| H3 视频 | 12.8-14GB | 独占全卡 |

## 四、模型部署实录

### 4.1 文生图：SDXL + Flux

SDXL 最简单，6.9GB 模型，60秒/张。

Flux 是真的强，但 16GB 跑全精度会爆。解决方案：**GGUF 量化版**（Q5_K_S，8.3GB），cfg=1，euler 采样，20步，2分20秒/张。

> 坑：Flux 用 cfg=7 会过饱和发灰，必须用 cfg=1（蒸馏模型特性）。

### 4.2 文生视频：MiniMax H3

这是最复杂的。H3 主模型 31.7GB（INT8 量化版），文本编码器 14.6GB，加起来 50GB+，16GB 显卡怎么跑？

答案：**offload + 量化 + Turbo LoRA**

- 主模型 INT8 量化（34GB → 实际占用 ~12GB）
- 文本编码器 NVFP4 量化（15.7GB → 按需加载）
- Turbo LoRA 把采样步数从 8 步压到 4 步，提速 50%+
- ComfyUI 自动 offload 到内存

实测：640×640 · 5秒视频 · 4步采样 · **~4分钟出片**（含原生音频）

> 坑1：TE-Speed 优化会导致文字乱码、手/嘴崩坏，必须禁用，只用 SageAttention。
> 坑2：首次生成 8-9 分钟是正常的（Sage/Triton JIT 预热），第2条起才是真实速度。
> 坑3：768p 是开源权重上限，别强求 2K/4K。

### 4.3 AI 写歌：MiniMax Music 3

最惊喜的一个。4.9GB 主模型 + 9.2GB 文本编码器，30秒歌 ~82秒生成，60秒 ~127秒。

输出 WAV 格式，质量超出预期——旋律、编曲、甚至人声都有模有样。

> 坑：TextEncode 的 `max_duration` 必须和 EmptyLatentAudio 的 `seconds` 一致，否则截断或报错。

## 六、总成本 vs 云端

| 项 | 本地（6500元硬件） | 云端（参考价） |
|---|---|---|
| 文生图 | 免费，60秒/张 | ~0.02元/张 |
| 文生视频(5s) | 免费，4分钟/片 | ~2-5元/片 |
| AI写歌(60s) | 免费，2分钟/首 | ~1-3元/首 |
| 对话 | 免费，不限量 | ~0.01元/次 |
| 隐私 | 数据全本地 | 需上传 |

如果每月生成 100 张图 + 20 个视频 + 20 首歌，云端约 100-200 元/月，本地硬件 2-3 年回本。但**隐私和不排队**是云端给不了的。
