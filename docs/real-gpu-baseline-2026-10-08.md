# 首次真实 GPU 基线：SDXL 512×512、8 步

2026-10-08 完成一次真实 ComfyUI 生成，后端对应任务 history 返回 success。此为采集链路与实际生成的基线验证，不是 GMae 相对其他调度器的性能对照，也不证明 Profile 已可用于准入。

## 原始证据与条件

公开[采样 JSON](evidence/sdxl-512-8steps-baseline-2026-10-08.json)保存全部 195 个样本、工作流、参数、任务身份、服务环境及终态。UTF-8/LF 文件 SHA-256：`f7b7ff64c68936982d1437dda5eee0779aa155f0b7d26ca1739d62fe91ddab14`。GPU UUID 已哈希，服务启动参数未公开；工作流与显存样本未修改。

- GPU：NVIDIA GeForce RTX 4060 Ti，16,380 MiB；驱动 591.86。
- 实际服务：ComfyUI 0.34.0，Python 3.10.12，PyTorch 2.5.1+cu121。容器 shell 的 Python 报告 PyTorch 2.14.0+cu130，不能替代运行中服务环境。
- 模型：工作流使用 `sd_xl_base_1.0.safetensors`；尚未记录模型文件摘要，不能证明模型二进制版本一致。
- 工作流：512×512、batch 1、8 步、CFG 6、seed 42；提示词与节点完整保存在 JSON。
- 开始前 ComfyUI 运行/待处理队列为空，Ollama 无驻留模型；未卸载模型、停止容器或中断已有任务。
- 显存通过 GPU 0 的 nvidia-smi 逐次查询采样，查询后等待约 0.2 秒；实际间隔包含进程启动及查询耗时，不是恒定 5 Hz。

## 观测结果与限制

任务提交到终态约 51.14 秒，包含本次运行的加载开销。起始整卡占用 1,741 MiB，采样到整卡最高占用 9,113 MiB；195 个样本，0 个采样错误。不能将整卡占用当作模型独占显存，不能将最高采样值当作绝对峰值或 OOM 保证。没有控制文件系统缓存、其他桌面活动及未受管客户端；没有重复运行、并发基线或吞吐对比。

本次首次采集发生在采集脚本新增资源操作日志检查、设备身份哈希和脚本摘要记录之前；公开记录对此版本差异作了说明。测量参数、采样方式与后端终态未改变。当前采集器已增强这些前置检查。
