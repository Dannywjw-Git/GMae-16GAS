# 持久 Ollama 任务与真实混合安全切换

2026-10-08，现有 RTX 4060 Ti / 16,380 MiB / 驱动591.86，ComfyUI 0.34.0 / torch2.5.1+cu121，Ollama0.33.0 / Qwen3.5:9b Q4_K_M。原单机 GPU 0 所有权、原 SQLite 任务/资源账本及2.5GiB保留空间下，两次执行 **SDXL → Qwen → SDXL** 串行队列；未并行常驻两个大模型。

## 新任务能力

新增 `queue_enqueue_ollama(request,idempotency_key)` 与 `/api/queue` 的 `source=ollama` / `request` 完整请求入口，使用与 ComfyUI 相同接收账本、串行 worker、任务状态与协调器。只有已安装的精确测量 Profile 才能接受 Ollama 请求；完整有效请求和证据引用在接收时固定，无 HTTP 任意峰值入口。幂等键跨后端共享，同键不同意图冲突。

发送前写入 submitting 和本地 submission_id；该 ID **不冒充 Ollama 后端历史 ID**。完整 done/model/token 回执持久化后才转终态，并保留输出摘要。超时、缺失响应或保存失败保留 uncertain/资源预留，不重放；重启时对已持久化的匹配完整回执恢复终态并关闭对应资源日志，没有回执则继续阻塞，不用 /api/ps 空列表猜测成功。

取消排队任务不发送；运行中保存取消意图，完整响应确认后标 canceled。**当前不提供 Ollama 即时中断**，不以关闭连接或全局 stop 声称对应请求已取消。普通队列 UI 尚未展示 Ollama 专用提交表单；现阶段提供 API 和可复现 CLI。明确有限输出、think=false、上下文<=8192、精确提示/参数绑定，没有按长度泛化预算。

## 两轮真实数据

| 轮次 | SDXL种子 | 任务完成 | 样本 | 整卡保守峰值MiB | 最低采样空闲MiB | 端到端秒 |
|---|---|---|---|---|---|---|
| 首轮 | 66 / 67 | 三项done | 1,084 | 8,912 | 7,468 | 279.281 |
| 记录增强后复核 | 68 / 69 | 三项done | 981 | 8,914 | 7,466 | 250.140 |

两次均零采样错误、终态后无未知任务/资源操作。每轮三项任务采用9217 / 8833 / 9217 MiB测量预算；SDXL512×512/8步/固定提示/cfg6，Qwen为6,182输入token、24输出token的已核验8K请求。不同轮次种子、代码记录能力和后台环境不同，**不比较加速比**。计时包含首次模型内容核验、排队、准入、释放及完成轮询，不是裸生成耗时。

首轮仅保留任务/样本与完成记录，没有完整协调事件，因此 `trace_verified=false`。复核记录完整协调事件和SQLite状态事件，独立分析核验每项 queued/precheck/submitting/running/done、真实后端顺序、固定引用和两次释放结果。释放命令成功与最终物理容量分开检查；最后的物理准入遥测满足对应预算+2560MiB。首轮暴露最终准入记录可能保留释放前遥测/峰值的问题，已修正并在复核中实际验收；首轮raw不重写。

初始释放返回时物理回收可能延迟，不能以命令回执即时 free_after 宣称空闲；后续 fresh 预算及最终遥测才许可目标提交。嵌套受管释放借用同一预留，会记录中间遥测，分析器选择其后的最终准入门，不能把中间值当最终值。

最后另受管卸载SDXL，核验低torch占用、空闲显存14,698MiB；Ollama无驻留模型、任务/资源账本无未确认工作。仅由实验产生的聚合 generation_stats 已本地备份并恢复，性能结论引用raw，不引用历史平均估计。

## 可复核材料

[完整raw、最终卸载、源码版本、摘要及独立汇总](evidence/mixed-durable-queue-20261008/manifest.json)。首轮代码 `5f9f4e4`，复核 `b498ec6`，完整提交见索引；后续采集器进一步要求任务终态、资源释放和日志关闭同时成立才退出。公开raw对临时token做摘要，LLM输出正文不发布，原账本中仍保留用于恢复的完整回执和输出摘要。

需要相同部署、经评审的SDXL cold/resident及Ollama证据安装于同一独立目录（manifest及raw须一并保留）后运行：

```text
python scripts/run_mixed_queue_trial.py --profile-dir <混合Profile目录> --ollama-raw <已安装相同Ollama校准raw> --first-seed 70 --output <新的raw>
python scripts/analyze_mixed_queue_trial.py <raw>
```

CLI取得原账本的真实GPU所有权，拒绝未结束任务、驻留Ollama、活动ComfyUI及Fooocus，不更换数据库绕过未知工作。输出拒绝覆盖；观察超时不重新提交。精确 Profile安装与摘要见此前SDXL/长Ollama报告。
