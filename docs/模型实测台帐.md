### 效果评价标准
- ⭐⭐⭐⭐⭐ (5)：惊艳，可直接用于专业作品
- ⭐⭐⭐⭐ (4)：良好，小修后可用
- ⭐⭐⭐ (3)：一般，能看出模型跑通了但质量普通
- ⭐⭐ (2)：较差，有明显瑕疵
- ⭐ (1)：失败或不可用

### 已知问题
1. ~~Flux GGUF 无法加载~~ ✅ 已修复：安装 ComfyUI-GGUF 节点 + gguf 依赖到正确目录
2. ~~H3 生成失败~~ ✅ 已修复：降低参数至 512×512/25帧（640×640/49帧会触发 comfy_aimdo HostBuffer 失败）
3. **ComfyUI 容器 overhead**：容器运行但模型卸载时约占 1.5-2G 显存（WSL2 + Python 进程）。
4. **comfy_aimdo 不可禁用**：ai-dock 镜像深度集成，禁用会导致 ComfyUI 启动失败。

## 使用说明

1. 每次生成后，Agent 应自动记录到 `model_benchmarks.jsonl`
2. 用户评价后，更新 quality_rating 和 quality_comment
3. 累积 3 次以上同模型数据后，取平均值校准 registry.json
4. 校准后更新本文件的"显存校准结论"表

*台帐数据是调度策略优化的基础，数据越多越准确。*
