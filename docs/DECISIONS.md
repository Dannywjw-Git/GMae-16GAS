| D006 | 两个会话通过 GitHub 交接，执行与独立监督并行 | 用户明确授权；阶段结束更新三份协作文档并标明独立评审主题，执行 Agent 不等待反馈，重大缺陷先修复。 |
| D007 | 普通工程决策自主，重大方向变更保留用户审批 | 不可逆删除、敏感公开、付费和最终参赛提交亦需审批；目标是 2026-10-16 前最大化实际获奖竞争力。 |
| D008 | 先验证 RPC 与账本之间的故障边界，再接入运行队列 | 提交前写入失败不发请求；提交后写入失败保留未知状态。`TaskDispatcher` 的 10 项测试支持此边界，但调用者保留资源及启动恢复仍须实现与验证。 |
| D009 | 先恢复未知任务的资源阻挡，再启用后台操作与 HTTP 服务 | 正式队列新增 7 项测试验证保存失败不释放、恢复不重放、多未知任务无释放空档；暂不宣传即时取消、跨进程锁或手动操作完整恢复。 |
| D010 | 取消只使用原子指定任务 API，确认响应不单独解除预留 | 本机 ComfyUI 0.34.0 源码与不存在任务协议检查支持该接口；指定 ID 的取消确认加严格队列缺失及新鲜 GPU 读数可用于结束核验。不支持后端不回退全局中断。真实 GPU 中断实验仍待完成。 |
