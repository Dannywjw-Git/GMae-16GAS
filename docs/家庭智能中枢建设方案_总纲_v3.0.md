## 一、项目定位与核心原则

### 1.1 一句话定位

> **家庭/小公司的私人 AI 大总管。** 核心：敏感数据存本地，本地算力先扛，扛不住自动脱敏调云端。**Open WebUI 为单一本地大脑 Hub**（记忆/知识库/角色 Agent/自动化/API 全闭环），全家各自独立账号用，姜维 Agent 承载家庭知识问答。

### 1.2 三条核心原则

1. **数据不出本地**：证件/保单/医疗/合同等敏感资料只存本地，不外泄第三方。
2. **本地算力优先**：日常对话、批改初稿、拍照答疑走本地 Ollama，免费且隐私。
3. **脱敏调云端**：长文档全量分析、深度批改等重负载，经 L1/L2/L3 脱敏后调用云端 API。

### 1.3 核心需求

| 需求                                 | 优先级 | 对应人 |
| ---------------------------------- | --- | --- |
| 家庭知识库（证件/保单/医疗/喜好/大事记）             | ⭐⭐⭐ | 全家  |
| 创业辅助（商业分析/合同审阅/文档撰写）               | ⭐⭐⭐ | 主公  |
| 雅思教学（写作批改/口语评估/阅读出题）               | ⭐⭐⭐ | 老婆  |
| 中考备考（全科复习/错题/学习计划）                 | ⭐⭐⭐ | 儿子  |
| 志愿填报（高中数据/分数线/策略模拟）                | ⭐⭐⭐ | 全家  |
| 数据安全（敏感资料不上云，脱敏调 API）              | ⭐⭐⭐ | 主公  |
| 多端接入（各电脑/手机浏览器 OWUI + WorkBuddy 可选） | ⭐⭐⭐ | 全家  |
| 照片/视频存储管理                          | ⭐⭐  | 全家  |

## 二、总体架构（框架）

### 2.1 逻辑架构

```
                  家庭局域网
  ┌──────────────────────────────────────────────────────────┐
  │  服务器（7×24h，装完物理隔离）                              │
  │  Open WebUI ← 单一本地大脑 Hub（记忆/知识库/Agent/自动化/API）│
  │  Ollama(本地模型)  Dify(标注库,Phase5决策)  n8n(复杂编排)     │
  │  Immich(相册)  Whisper(语音)  SearXNG(搜索)  Caddy  rerank  │
  │  family-bridge(网关,Phase4退役)  Nextcloud(文件)             │
  │                        │ Ollama API :11434（仅局域网）      │
  └────────────────────────┼─────────────────────────────────┘
                           │ 外出：Tailscale 加密隧道（Caddy ts.net HTTPS 为辅）
            ┌──────────────┼──────────────┐
       ┌────┴────┐   ┌────┴────┐   ┌────┴────┐
       │ 主公WB  │   │ 老婆WB  │   │ 儿子WB  │   ← 各独立账号（OWUI 网页为主入口）
       └─────────┘   └─────────┘   └─────────┘
       手机/平板：浏览器 + Tailscale App（华为/iPad 均已装）
```

> 模型分层（08-08 复盘定策 + 08-15 演进）：**家人聊天/百科 → 云端 DeepSeek（聪明问答）**（便宜 4-7 元/月）；**家庭数据查询 → 姜维 Agent（jiangwei，本地 9B + 7 库 RAG，OWUI 默认模型）**（豆包做不到的差异化）；**财务敏感 → 管仲本地**。不再让家人用本地小模型。

### 2.2 算力分工（08-08 模型分层定策）

|                      | 主公                 | 老婆            | 儿子      |
| -------------------- | ------------------ | ------------- | ------- |
| **云端 DeepSeek**（聪明问答） | ✅ 日常聊天/百科 | ✅ 备课/批改初稿 | ✅ 答疑/错题 |
| **姜维 Agent**（jiangwei，OWUI 默认） | ✅ 家庭数据查询（豆包做不到的差异化） | ✅ 家庭数据查询 | ✅ 家庭数据查询 |
| **管仲本地**（财务敏感）      | ✅ 持仓/止损/仓位/资产配置 | —       | —       |
| **知识库**              | OWUI（7 库，姜维自动 RAG） | OWUI  | OWUI |

> ⚠️ 教训（08-08 复盘）：**本地小模型天花板低是家人弃用的主因之一**——不再让家人用本地小模型；云端 DeepSeek 便宜（1/2 元每百万 token，家用月 4-7 元）且智能够用。

### 2.3 检索架构

```
用户提问 → 姜维 Agent（OWUI，自动带 7 库）
  ├── 精确查找（"分数线多少""合同在哪"）→ OWUI Knowledge RAG + bge-m3 embedding → 精确结果
  └── 全局分析（"作文错误趋势""合同共性风险"）
       → 知识库导出 → 脱敏 → Kimi K3 全量分析（100万 token 上下文）→ 交叉分析报告
```

> 检索配置、rerank、Filter 注入等技术细节 → `docs/技术细节_知识库与记忆系统.md` + `docs/智能中枢_OWUI升级方案_完整版_v1.md`

> **外部客户端入口**：WorkBuddy / 手机端等走 OpenAI 协议的客户端，不直接调用 Dify，统一经 **family-bridge（:8000，OpenAI 兼容 `/v1/chat/completions`）** 访问大脑链路；该服务把 Dify RAG + 姜维记忆 + SearXNG 联网 + qwen2.5:14b 封装成标准接口，使任意 OpenAI 兼容客户端都能用上家庭大脑（详见 `docs/WorkBuddy自定义模型配置指南.md`）。
> 🏛️ **架构收敛方向（08-14 起，主路线）**：OWUI 升格为**单一本地大脑 Hub**（Memory/Knowledge/Agents/Automations/API 全闭环），family-bridge 与手搓层随 `docs/智能中枢_OWUI升级方案_完整版_v1.md` Phase 4 退役；当前 Phase 0/0.5/1 已完成——Dify 7 库 113 文档已迁 OWUI，正式姜维 Agent 上线。过渡期 family-bridge 仍可用。

### 2.4 远程访问框架

**原则**：端口不暴露公网（路由器 NAT 两表已确认无转发），全部走加密隧道。Tailscale 为主（三端华为/iPad/多台 Windows 均已装，`100.102.52.12` 直连），**Caddy 保留使用**（08-09 决策反转：是全家经 ts.net 访问各服务的统一 HTTPS 入口，已加固安全响应头），WireGuard 已停用（wg-easy 已删除）。

> 设备清单、Tailscale / Caddy HTTPS、网络安全与备份 → `docs/技术细节_远程访问与网络安全.md`
> ⚠️ 多入口 cookie 域不共享：同服务经 IP / Tailscale IP / ts.net 域名访问 cookie 各自落 → 401 循环/闪烁；统一走一个域可解。

### 3.2 数据脱敏（L1/L2/L3 三级框架）

| 级别     | 方法                           | 准确率   |
| :----- | :--------------------------- | :---- |
| L1 规则级 | 正则匹配身份证/手机/银行卡/邮箱            | ~99%  |
| L2 模型级 | Qwen3.5-9B 做 NER 识别人名/公司名/地名 | ~90%  |
| L3 人工级 | 高敏场景脱敏后扫一眼再发出                | ~100% |

流程：原文 → L1 → L2（人名→本地映射表）→ L3 确认（高敏强制）→ 发云端 → 查表还原。

### 3.3 自动化（n8n 核心工作流框架 + OWUI Automations 分工）

- **每日播报**：天气 + 日程 + 学习计划 + 订单。
- **文档入库**：微信转发企微机器人 → 知识库自动入库。
- **作文批改**：学生作文脱敏 → 批改 → 结果还原。

> 🏛️ 08-15 分工定策（OWUI 升级方案 Phase 2 待落地）：**简单定时 → OWUI Automations**；**多步跨系统编排（OCR→入库→通知）→ n8n**；文档入库目标改指单一事实源（KB Sync 目录）。

### 3.4 三大核心场景（框架 + 入口）

- **老婆 · 雅思教学**：备课（生成题目+范文+词汇→本地 Ollama→存库复用）；批改（L2 脱敏→L3 确认→Ollama 基础 + Kimi K3 深度→还原存档）；趋势分析（全班导出→Kimi K3 全量）。**+ 家庭管家**：菜谱/采购清单/日程协同/健康备忘/生活问答。
- **儿子 · 初三备考 + 志愿填报**：答疑(Ollama)/拍照错题(VL 识别)→错题本→同类题；志愿填报（排位+通勤→冲刺/稳妥/保底三套）。**+ 趣味伙伴**：写作玩伴/兴趣问答/游戏攻略/英语应用/心理陪伴。
- **主公 · 创业辅助**：商业模式分析 / 合同审阅（脱敏→Kimi K3 全量→风险标注）/ 竞品动态周报。

> 入口建议：手机浏览器 Open WebUI 最佳（打开就聊）。专业与生活场景共用同一后台，家人只需记一个入口。

## 四、数据安全与合规（原则层）

### 4.4 敏感边界

记忆文档存本地（`memory_docs/`，唯一权威源），不含密钥/凭据；家人姓名生日等由主公口述积累，不落明文到第三方。
