## 一、核心逻辑（声量的公式）

```
声量 = 内容质量 × 传播节点 × 渠道覆盖
```

- **多平台是"放大器"，不是"源头"**——真正的声量来自"引爆点"（一个惊艳瞬间、一个共鸣叙事），渠道只是把引爆的能量放大。
- 打法不是"到处发"，而是 **造好弹头 + 架好发射架 + 全渠道齐射**。

## 二、一鱼多吃的生产流水线（弹药工厂）

一个素材 → 多种形态 → 全平台分发。以「Fooocus vs Flux 测评」为例：

| # | 形态 | 渠道 | 打的人群 |
|---|------|------|---------|
| ① | 图文帖 | V2EX / 知乎 | 技术圈口碑 |
| ② | 60 秒短视频 | B站 / 抖音 | 流量池 |
| ③ | 英文帖 | Reddit r/StableDiffusion | 全球玩家 |
| ④ | 长文 | 公众号 / 作品介绍 | 深度 |
| ⑤ | 素材沉淀 | README / 官网截图 | 长期资产 |

**AI 的角色**：批量生成各平台文案（各自调性）、中英互译、视频脚本、自动响应评论、周报数据。
**人的角色**：只花精力在"决策和把关"。

## 三、渠道矩阵（中英双线，主次分明）

| 层级 | 渠道 | 定位 |
|------|------|------|
| **主战场**（最大投入） | B站 / 抖音（中文短视频流量最大）；Reddit（英文 AI 核心圈）+ Hacker News Show HN（英文引爆点） | 流量源头 |
| **次战场**（口碑沉淀） | 知乎 / 即刻 / V2EX（中文技术圈）；YouTube（英文长视频）+ X/Twitter | 沉淀口碑 |
| **辅助**（长尾） | Product Hunt（产品化后）+ 公众号 / 小红书 | 长尾覆盖 |

## 四、引爆逻辑（四个"主动触发点"）

声量不是靠"发得多"，是靠**触发传播**：

1. **一个 wow 瞬间**——秒级释放的视频，让人主动转发
2. **一个共鸣叙事**——"文科生用 AI 做极客项目"，媒体爱写
3. **一个普遍痛点**——显存不够是每个 AI 玩家的痛，自来水
4. **大赛获奖**——官方背书，第二波流量

## 五、AI 原生运营的分工

- **你（人）**：决策、把关、出镜（如需）、盯关键节点
- **AI 们（豆包/WorkBuddy/DSH）**：批量生产 / 翻译 / 分发 / 响应 / 追踪

**生产节奏（可并行、可放量）**：
- 每周 1-2 个主题 → 每主题出 4-5 形态 → 全平台分发
- 用点子库当弹药仓库，攒够就发一轮

## 六、三个务实提醒

1. **声量 ≠ 质量**：全渠道铺开容易稀释质量、反噬口碑——每个平台的内容都要"为该平台优化"，不是同一篇复制粘贴
2. **AI 产出要过你的关**：批量生成容易"AI 味"，发布前你审一遍（呼应"少即是多"——宁可每篇精，不可每篇水）
3. **开发主线 vs 运营支线**：运营别吃掉开发时间——点子库 + 定期集中整理就是为了让运营"攒着做"，不打断主线
