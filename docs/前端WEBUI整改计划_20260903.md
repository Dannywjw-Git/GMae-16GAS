### 2.1 设置页"去假存真"（2天）

**问题确认**：
`pages.js` 第1751-1900行的 `settings()` 和 `_renderSettingsSection()` 中，7个配置分区全部是硬编码静态HTML：
- 所有"保存更改"/"保存配置"/"修改密码"按钮无id、无onclick、无事件绑定
- 服务管理表格（第1821行）硬编码5个服务，状态永远"在线"
- 看门狗"PID 12345 · 运行2小时30分"（第1887行）是假数据
- `<div class="toggle"></div>`（第1840、1852行）是纯div，不可点击
- 输入框值全是写死的（"8787"、"8 GB"、"5 秒"等）

**整改方案**：

#### 2.1.1 系统配置分区（0.5天）

**改动文件**：`web/js/pages/pages.js` `_renderSettingsSection()` 的 `system` 分支

**具体改动**：
1. 页面加载时调用 `API.getStatus()` 和 `API.getHealth()`，读取真实的服务端口、监听地址
2. 给输入框添加id：`setting-port`、`setting-host`、`setting-log-level`、`setting-cache-ttl`、`setting-refresh-interval`
3. 给"保存更改"按钮添加id `btn-save-system`，绑定onclick：
   ```javascript
   Utils.$('#btn-save-system').onclick = async () => {
     const config = {
       port: parseInt(Utils.$('#setting-port').value),
       host: Utils.$('#setting-host').value,
       log_level: Utils.$('#setting-log-level').value,
       cache_ttl: parseInt(Utils.$('#setting-cache-ttl').value),
       refresh_interval: parseInt(Utils.$('#setting-refresh-interval').value),
     };
     const res = await API.post('/api/config', config); // 需后端确认是否有此端点
     if (res.ok) Toast.success('配置已保存');
     else Toast.error(res.error?.message || '保存失败');
   };
   ```
4. "恢复默认"按钮绑定确认弹窗后重置为默认值

**注意**：如果后端没有 `/api/config` 端点，需要先在后端添加（`api/endpoints/config.py`），或者将不可配置的项标记为"只读"。

#### 2.1.2 服务管理分区（0.5天）

**具体改动**：

## 六、风险与注意事项

1. **后端API缺失风险**：部分整改方案假设后端已有对应API（如 `/api/config`、`/api/scene` 返回所有场景列表）。如果后端没有，需要先加后端API，工时会增加。

   - **应对**：优先推动后端增加 `/api/scene/status` 端点返回当前步骤

   - **应对**：短期用前端静态映射，中期推动后端增加模型评测API

   - **应对**：拆分前确保所有功能正常，拆分后逐页面测试，保留原文件备份直到验证完成
